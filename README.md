# brieff — 교안 삽화 자동 생성기

한국열린사이버대학교 교안(PPT/PDF/DOCX/텍스트/캡처 이미지)을 넣으면, **파란색 톤의 전문적인 플랫 아이콘
인포그래픽 스타일**(은행 건물, 저울, 문서, 체크마크 등 실제 아이콘 팩 스타일) 삽화를 슬라이드마다
4:3 비율로 자동 생성하는 개인용 도구입니다. 이미지 생성은 OpenAI의 이미지 생성 모델(`gpt-image-1`,
이른바 "챗GPT 이미지 생성")을 사용합니다.

- 모든 이미지는 동일한 색상(네이비/미디엄블루/스카이블루)·아이콘 화풍·구도를 강제하는
  고정 프롬프트 템플릿(`illustrator/style.py`)을 공유하므로, 여러 장을 만들어도 하나의 세트처럼 보입니다.
- 캐릭터(마스코트)로 통일성을 주는 대신, 주제에 맞는 아이콘(은행 건물, 저울, 문서, 경고 삼각형,
  동전, 계산기, 체크리스트 등)의 화풍·색상·구도를 통일해서 일관성을 만듭니다. 브리피 마스코트는
  선택 사항으로 켤 수 있습니다.
- 이미지 안에는 글자를 전혀 넣지 않도록 프롬프트에 명시합니다(한글은 이미지 생성 모델이 정확히
  그리지 못하는 경우가 많음). 제목·설명 텍스트는 PPT 안에서 직접 편집하는 걸 권장합니다.
  본문 내용은 GPT로 한 문장짜리 아이콘 컨셉으로 압축한 뒤 그림에 반영합니다.
- `gpt-image-1`은 정확한 4:3 크기를 직접 지원하지 않으므로, 가장 가까운 크기(1536x1024)로 생성한 뒤
  가운데를 잘라 정확히 4:3(기본 1920x1440, 고해상도)으로 만듭니다.

## 출력 모드 두 가지

1. **인포그래픽 슬라이드 (기본, 추천)** — 첨부 예시 슬라이드처럼 용어+한줄설명+아이콘이 조합된
   완성된 슬라이드 한 장을 자동으로 만듭니다. GPT로 슬라이드 내용에서 (용어, 설명) 항목을 뽑아내고,
   항목마다 작은 아이콘을 AI로 생성한 뒤, 번들된 한글 폰트(Pretendard, OFL 라이선스)로 직접
   텍스트를 그려 넣어 조합합니다 — 한글 텍스트는 이미지 생성 모델이 아니라 코드로 그리기 때문에
   글자가 항상 정확합니다. 레이아웃은 3종류 중 선택 가능:
   - **번호 카드형**: 원 안에 숫자 + 용어 + 설명 + 아이콘 (참고 이미지의 "국세/세법/원천징수/가산세" 스타일)
   - **표(용어/의미)형**: 헤더가 있는 표 형태 (참고 이미지의 용어-의미 표 스타일)
   - **비교(2단, VS)형**: 두 개념을 좌우로 비교 (참고 이미지의 "시가표준액 vs 공정시장가액비율" 스타일)
   - **자동**: 항목이 2개면 비교형, 그 외에는 번호 카드형을 자동 선택
2. **아이콘 단일 이미지** — 슬라이드 하나당 아이콘 그림 한 장만 생성해서 PPT에 장식용으로 삽입하고
   싶을 때 사용하는 기존 방식입니다.

## 설치

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # OPENAI_API_KEY 입력
```

## 사용법 1 — 웹 UI (추천, 혼자 쓰기 편함)

```bash
streamlit run app.py
```

브라우저가 열리면 PPT/PDF/DOCX/텍스트를 업로드하거나 텍스트를 붙여넣고 "삽화 생성하기"를 누르면
슬라이드별 삽화가 갤러리로 표시됩니다. 개별 이미지를 다운로드하거나, PPT를 업로드한 경우
"PPT에 삽화 삽입하여 다운로드용 파일 생성" 버튼으로 삽화가 들어간 사본을 받을 수 있습니다.

- **미리보기 모드**를 켜면 API를 호출하지 않고 어떤 프롬프트가 생성될지만 확인할 수 있어(비용 없음),
  본격적으로 이미지를 생성하기 전에 문구를 점검하기 좋습니다.

## 사용법 2 — CLI (배치 처리)

```bash
# PPT 전체 슬라이드에 대해 삽화 생성 + 삽화가 삽입된 PPT 사본까지 생성
python cli.py --input lecture01.pptx --output-dir out/lecture01 --embed

# 텍스트만으로 빠르게 생성 (빈 줄로 슬라이드 구분)
python cli.py --text "$(cat notes.txt)" --output-dir out/quick

# API 호출 없이 프롬프트만 미리 확인 (비용 없음)
python cli.py --input lecture01.pptx --output-dir out/preview --dry-run

# 인포그래픽 슬라이드 모드 (번호카드/표/비교 레이아웃)
python cli.py --input lecture01.pptx --output-dir out/lecture01 --infographic --layout auto
```

## 스타일 커스터마이징

`illustrator/style.py`의 `ICON_SUBJECT_HINT`, `PALETTE`, `STYLE_KEYWORDS`를 수정하면
모든 이후 생성 이미지에 일괄 반영됩니다. 색상은 기본적으로 네이비(#173A8A)·미디엄블루(#1E6FD9)·
스카이블루(#5FB6E8) 조합입니다.

## 지원 입력 형식

| 형식 | 처리 방식 |
| --- | --- |
| `.pptx` | 슬라이드별 제목 + 본문 텍스트 추출, `--embed`로 결과를 원본 PPT에 재삽입 가능 |
| `.pdf` | 페이지별 텍스트 추출 (첫 줄을 제목으로 간주) |
| `.docx` | 제목 스타일 문단 기준으로 섹션 분리 |
| `.txt` / 직접 입력 텍스트 | 빈 줄(`\n\n`) 기준으로 슬라이드 단위 분리 |
| 참고 이미지 (선택) | 업로드 시 `images.edit`으로 스타일 참고에 활용 |
